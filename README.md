# 🍵 Sonsuz Çay Demleme Bekleyicisi

Bu repository, insanlık tarihinin en büyük sabır testini temsil etmektedir. 

## Ne Yapar?

Hiçbir şey. Kesinlikle hiçbir şey. Çay demlenene kadar bekler. Ama çay hiç demlenmez. Çünkü demleme işlemi sonsuz bir döngüde sıkışmıştır.

### Kullanım

```bash
python cay_demle.py
```

Ve bekleyin. Sonsuza kadar. Çayınız asla hazır olmayacak. Bu bir özellik, bug değil.

## Özellikler

- %100 gerçek çay demleme deneyimi (hayali)
- Sonsuz bekleyiş garantisi
- Çay asla bitmez çünkü hiç başlamaz
- CPU'nuzu yormaz, sadece ruhunuzu yorar

## Uyarı

Bu scripti çalıştırdıktan sonra çayınızın demlenmesini bekliyorsanız, ölümsüz olmanız gerekmektedir. Aksi takdirde ölüm sizi bulur, çay sizi bulmaz.

## Katkıda Bulunma

Lütfen katkıda bulunmayın. Çay demlenmesin diye uğraşıyoruz.
